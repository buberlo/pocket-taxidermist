# Pocket Taxidermist

> Stuffed app icons preserve the digital animals you forgot to feed.

A mobile utility that turns abandoned apps into mounted trophies using usage time and launch frequency. Each forgotten app gets a plaque, a preservation score, and a tiny ritual to reanimate it.

## Features
- Scan recent app usage and classify dormant apps
- Render each app as a preserved specimen with a plaque
- Track a decay meter based on days without launch
- Offer a one-day resurrection ritual with a reminder

## Stack
- React Native
- Expo
- SQLite
- Reanimated

## Getting started
```
npm install && npx expo start, then open on a device with usage access, notifications, and background fetch permissions enabled.
```
